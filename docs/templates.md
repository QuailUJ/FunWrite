# 字庫與新增字

## 2.1 介面操作

主畫面「練習字與位置」可直接換字、調整 1～12 個位置；上排 1～6、下排 7～12，使用前 N 個位置。
重複選到已使用的字會交換兩個位置，不產生重複字。按「儲存並套用」即生效，重開保留。
未評分筆跡需先處理；保留字的結果會隨字移動，移出字的畫面結果不保留，但已存檔案與金幣不刪除。

新增目前沒有的字：輸入中文字後按「匯入字庫」，成功後從下拉選單指定位置並儲存。
新增使用 `external/makemeahanzi/dictionary.txt` 與 `graphics.txt`，不連網、不需 Git 或 PowerShell。
需保留這兩個原始資料檔與授權；目前固定為 `bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 字源。
每批最多 12 字，支援 U+4E00～U+9FFF 且最多 16 筆；字源沒有、資料不完整或超過範圍會提示，整批不部分新增。
已有字不覆寫，匯入也不會自動改字單；取消設定後已成功匯入的字仍留在字庫。
字單寫入採暫存檔替換，上一次字單保留為 `assets/practice-words.txt.previous`。

## 原有字庫與命令工具

練習字單為 `assets/practice-words.txt`，每行一字、最多 12 字，按檔案順序對應上排六字、下排六字。
改字單後重新開啟程式，不需要重新編譯。預設為一、二、四、五、六、七、八、乃、朵、思、土、士。

已匯入的字為思、土、士、日、月、人、大、天、木、林、明、好、家，存於 `assets/hanzi`。
同字存在 JSON 時優先使用；否則使用 `assets/templates` 的乾淨整筆範例。
這些 TXT 是重構前讀取結果的等價轉存，原始手寫檔保留在備份。

在專案根目錄匯入其他字：

```powershell
.\tools\Import-Hanzi.ps1 -Characters '山水火'
```

工具離線讀取 `external/makemeahanzi`，保留 SVG 輪廓、中心線、拆解、筆畫部件對應與來源版本。
程式使用中心線評分及顯示，沒有把部件或單筆分開放大。
時間與壓力為範例的合成資料，不作真實速度與力量標準。

目前部件結構檢查支援資料完整的最外層上下（⿱）及左右（⿰）結構。
已匯入字中，土、天、好、明、林、思、家有適用分組。包圍、重疊及深層部件尚未逐層評分，
沒有分組時維持整筆字形檢查。筆數不符仍對所有字限制最高 59 分。

上游以 PRC 筆順為主，這批尚未逐字核對台灣教育部標準。匯入檔的 `taiwanStrokeOrderVerified` 保持 false。
授權原件保留在 `external/makemeahanzi/COPYING`、`LGPL` 與 `APL`，主程式不需要連網。
